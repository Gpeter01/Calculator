# Calculator
This is a demo calculator that performs basic mathematical calculations.

## *Key features*
- Division, multiplication, addition, and subtraction operations.
- Floating-point number calculations.
- Negative numbers for a wider range of calculations.
- Basic calculator functions such as deletion, clear, and result.
- An auto-updating display that reflects user input.

## *Conclusion*
This project serves as a sign of growth and showcases our capabilities, which is remarkable. The project incorporates learned concepts and deepens understanding of JavaScript and DOM manipulation. It also emphasizes the importance of code structuring and planning, which is arguably the most valuable takeaway.
